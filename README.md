# Random Football

Стартовый веб-проект для Random Football: Next.js + TypeScript + Supabase.

## Локальный запуск
1. Установите Node.js 20+.
2. Скопируйте `.env.example` в `.env.local` и заполните ключи Supabase.
3. Выполните `npm install`, затем `npm run dev`.
4. Откройте http://localhost:3000.

## База данных
В Supabase откройте SQL Editor и выполните `supabase/schema.sql`, затем `supabase/seed_demo.sql`.

В seed-файле данные явно помечены как `demo`; рейтинги не являются подтверждёнными официальными рейтингами FIFA.

## Публикация
Импортируйте репозиторий в Vercel, добавьте переменные окружения Supabase и нажмите Deploy.

## Важно
- Не помещайте `service_role` key в браузер или публичные переменные.
- До коммерческого запуска проверьте права на названия, эмблемы, изображения и базы рейтингов.
- Настоящая real-time игровая механика и турнирный матчмейкинг пока не реализованы: этот каркас — первый этап.
